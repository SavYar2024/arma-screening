# Дзеркало порталу «Реєстр активів АРМА»

Копія інтерфейсу робочої системи для перевірки (GitHub Pages). Дані — знімок бази сервера без персональних відомостей.

* Портал: `index.html` — оберіть роль на сторінці входу (без пароля).
* Публічний сайт: `public.html`.
* Зміни зберігаються лише у вашому браузері.
* Оновлення: на сервері «Адміністрування → Дані, імпорт, дзеркало → Сформувати дзеркало для GitHub», завантажити файли сюди замість попередніх.
